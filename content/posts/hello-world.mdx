### 三级标题：代码块

下面是一个 JavaScript 代码块，应当带 Shiki 语法高亮，并且在 light / dark / reader 三个主题间换色：

```js
// 一个简单的斐波那契实现
function fib(n) {
  if (n < 2) return n;
  return fib(n - 1) + fib(n - 2);
}

console.log(fib(10)); // 55
```

> 这是一段引用（blockquote）。极简、留白、动效轻、阅读优先——这是 Sephire Lab 的设计原则。
